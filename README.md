# HDMI тест

Маленький застосунок для телевізора Bravis LED-32G5000 Smart+T2 (Android 7).
Перевіряє, чи може сторонній застосунок показувати картинку з HDMI без
штатного лаунчера. Якщо може, на цій основі буде зроблено власний лаунчер.

## Що він робить

- показує всі входи (HDMI тощо), які бачить Android, і їхній стан;
- **рядок з назвою входу**: пробує вивести HDMI у вікно праворуч (як це робитиме наш лаунчер);
- **«-> відкрити системою»**: просить систему відкрити вхід (так робить Projectivy);
- **«Діагностика»**: список лаунчерів, ТВ-застосунків і їхніх внутрішніх екранів;
- показує код кожної натиснутої кнопки пульта (щоб дізнатися код Source).

## Збірка

APK збирає GitHub Actions при кожному push у `main`.
Готовий файл: розділ **Releases → «Остання збірка» → hdmi-test.apk**.
